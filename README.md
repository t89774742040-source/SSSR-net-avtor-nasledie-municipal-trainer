# Наше наследие — муниципальный тур, 3–6 классы

Полная версия учебного тренажёра: 9 тем, 9 кроссвордов, 4 обзорных теста, 20 изображений, пошаговые решения и цветная проверка ответов.

## Файлы

- index.html — страница приложения.
- app.js — интерфейс, проверка и сохранение прогресса.
- style.css — оформление.
- data.json — учебные тексты, задания, ключи, сетки и решения.
- assets/ — исходные PDF и изображения.

Сайт не требует сборки или установки библиотек. Прогресс хранится в браузере.

## Как сохранить через GitHub Desktop

1. Создайте новый репозиторий: File → New repository. Название: nasledie-municipal.
2. Откройте папку репозитория: Repository → Show in Explorer.
3. Скопируйте в неё содержимое папки из ZIP: index.html, app.js, style.css, data.json, assets и остальные файлы. Не добавляйте дополнительный уровень вложенности.
4. В GitHub Desktop в Summary введите «Сохранить тренажёр муниципального тура».
5. Нажмите Commit to main, затем Publish repository.
6. Выберите видимость репозитория и подтвердите Publish repository.
7. Кнопка View on GitHub откроет сохранённый репозиторий.
